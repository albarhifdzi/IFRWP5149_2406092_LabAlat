# Tabel Temuan dan Perbaikan

| No. | Temuan                                                   | Perbaikan yang Diperlukan                                         | Alasan |
| 1 | Mahasiswa terhubung dengan fungsi mengelola jadwal kuliah. | Hapus hubungan Mahasiswa dengan use case Mengelola Jadwal Kuliah. | Mahasiswa hanya diperbolehkan melihat jadwal kuliah. |
| 2 | Admin Akademik terhubung dengan fungsi melihat jadwal kuliah. | Hapus hubungan Admin Akademik dengan use case Melihat Jadwal Kuliah. | Admin bertugas mengelola jadwal, bukan berperan sebagai mahasiswa. |
| 3 | Fungsi melihat jadwal kuliah belum dijelaskan secara terperinci. | Tambahkan use case Melihat Daftar Jadwal Kuliah dan Melihat Detail Jadwal Kuliah jika diperlukan. | Agar aktivitas mahasiswa lebih jelas. |
| 4 | Fungsi mengelola jadwal kuliah belum dirinci. | Tambahkan use case Menambah, Mengubah, dan Menghapus Jadwal Kuliah. | Agar tugas Admin Akademik lebih terperinci. |
